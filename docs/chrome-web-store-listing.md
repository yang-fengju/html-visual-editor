# Chrome 网上应用店上架资料

## 基本信息

- 名称：HTML Visual Editor
- 类别：开发者工具
- 语言：简体中文
- 单一用途：让用户在其主动选择的当前网页上，本地进行可视化 HTML 编辑、批注和导出。

## 简短说明

像使用 Word 一样直接编辑当前网页的 HTML，支持样式调整、批注、撤销重做和本地导出。

## 详细说明

HTML Visual Editor 是一个完全在浏览器本地运行的网页可视化编辑工具。用户主动开启编辑模式后，可以直接选择网页元素、编辑文字、调整样式、移动内容、修改表格与表单，并为页面添加批注和便签。

主要功能：

- 直接选择和编辑当前网页中的文字与元素。
- 调整颜色、字体、间距、边框等样式。
- 支持拖拽排序、表格编辑、媒体替换和表单属性修改。
- 添加文字批注、段落批注和便签。
- 使用撤销和重做恢复编辑操作。
- 将编辑结果导出为 HTML，或复制完整 HTML。
- 将批注导入或导出为 JSON 文件。

所有网页内容和批注均在用户设备本地处理。本扩展没有开发者服务器，不会上传、共享或出售用户数据。

## 权限审核说明

### activeTab

仅在用户点击扩展图标或执行 `Alt+E` 快捷键后，临时访问用户当前选择的标签页，用于开启可视化编辑。扩展不会持续访问其他标签页。

### scripting

在用户主动开启编辑模式后，将扩展包内的 `content.js` 注入当前标签页，用于创建编辑器界面和执行本地网页编辑。本扩展不加载或执行远程代码。

### storage

用于在用户设备本地保存隐私授权状态、首次使用提示状态，以及与具体页面关联的批注和便签。数据不会同步到开发者服务器。

### downloads

仅在用户点击导出命令时，将用户当前编辑的 HTML 下载到其设备。扩展不会读取、修改或管理其他下载记录。

## 用户数据披露

需要披露的数据类型：

- 网站内容：用于本地选择、编辑、预览和导出当前网页。
- 网络浏览活动：使用当前网页地址和标题关联本地批注，不会收集连续浏览历史。
- 用户生成内容：用户主动创建的批注、便签及其关联的选中文字。

数据处理承诺：

- 仅为扩展公开说明的单一用途处理数据。
- 不出售或向第三方传输用户数据。
- 不将用户数据用于与单一用途无关的目的。
- 不将用户数据用于信用评估或贷款。
- 不将用户数据用于个性化广告。
- 不允许人工读取用户数据。

## 审核测试说明

1. 打开任意普通 HTTPS 网页。Chrome 内部页面和 Chrome 网上应用店页面不允许扩展注入，这是浏览器限制。
2. 点击扩展图标，开启“编辑模式”；首次使用时在网页授权界面点击“同意并开启”。
3. 单击网页元素应显示选择框，双击文字应进入编辑状态。
4. 使用顶部工具栏修改样式、插入元素并执行撤销或重做。
5. 添加一条批注，刷新页面后再次开启编辑模式，批注应从本地存储恢复。
6. 点击“导出 HTML”并确认浏览器成功下载文件。
7. 也可以使用 `Alt+E` 快捷键开启或关闭编辑模式。

本扩展不需要账号、登录凭据、付费功能或外部服务。
