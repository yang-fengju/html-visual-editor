# HTML Visual Editor 隐私政策

生效日期：2026 年 8 月 4 日

HTML Visual Editor（以下简称“本扩展”）用于在用户主动选择的当前网页上进行本地可视化 HTML 编辑、批注和导出。本政策说明本扩展如何处理用户数据。

## 处理的数据

本扩展仅在用户主动开启编辑模式并明确同意后，处理以下数据：

- 当前网页的内容和结构，用于选择、编辑、预览和导出 HTML。
- 当前网页的完整地址和标题，用于把本地批注与对应页面关联。
- 用户主动创建的批注、便签和相关选中文字，用于在再次打开对应页面时恢复批注。
- 扩展设置，例如用户是否已经确认隐私说明和是否关闭首次使用提示。

## 数据用途

上述数据只用于提供本扩展公开说明的单一用途：在当前网页上进行本地可视化编辑、批注和导出。本扩展不会把这些数据用于广告、用户画像、信用评估或任何与该用途无关的目的。

## 数据存储与传输

- 网页内容仅在用户当前浏览器标签页中临时处理。
- 页面地址、页面标题、批注和扩展设置保存在 Chrome 提供的扩展专用本地存储中。
- 本扩展没有开发者服务器，不会把上述数据上传给开发者或第三方。
- 本扩展不会出售、共享或允许人工查看用户数据。
- 用户主动填写外部图片或媒体地址时，浏览器可能按照该地址直接请求对应资源；该请求由用户选择的资源服务方处理，不会经过开发者服务器。

## 数据保留与删除

批注会保留在用户设备上，直到用户在扩展中删除相应批注或卸载本扩展。卸载扩展后，Chrome 会清除扩展专用本地存储中的数据。用户导出的 HTML 或 JSON 文件由用户自行管理，本扩展无法在导出后访问或删除这些文件。

## 权限说明

- `activeTab`：在用户点击扩展或使用快捷键后，临时访问当前标签页。
- `scripting`：在用户主动开启编辑时，将随扩展打包的编辑器代码注入当前页面。
- `storage`：在本机保存隐私授权状态、扩展设置和用户批注。
- `downloads`：根据用户明确操作下载导出的 HTML 文件。

## 有限使用承诺

本扩展对用户数据的使用遵守 Chrome 网上应用店用户数据政策，包括 Limited Use（有限使用）要求。所有数据处理均限于提供或改进本扩展公开说明的单一用途。

## 政策变更

如果本扩展的数据处理方式发生变化，将在新的处理开始前通过扩展界面显著告知用户，并在需要时重新取得用户同意。本政策也会同步更新。

## 联系方式
